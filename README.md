# 照片初筛工具

Repository: `photo-cull`

照片初筛工具的统一代码仓库，包含网页端、macOS 本地端和 iOS 原生端。
照片内容分析在本机或 iPhone 上进行，不会由本工具上传到云端。

## 版本目录

| 版本 | 代码位置 | 运行方式 |
| --- | --- | --- |
| 网页端 | 仓库根目录的 `index.html`、`app.js`、`styles.css` | 用项目已有的 Node/npm 工作流构建；保持根目录结构以兼容现有托管配置 |
| macOS 本地端 | [`tools/`](tools/README.md) | 从 `tools/照片初筛工具.command` 启动；它会在照片目录生成独立结果页面 |
| iOS 原生端 | [`iOS/拣片/`](iOS/拣片/README.md) | 用 Xcode 打开 `iOS/拣片/拣片.xcodeproj`，选择设备后运行 |

## 单一源代码原则

- 本仓库是网页端、Mac 端和 iOS 端的代码主目录。功能修改先进入这里，并在验证后同步 Mac 桌面运行包。
- `~/Desktop/照片初筛工具/` 是方便直接启动和分享的 Mac 运行副本，不是另一条独立开发分支。用 `tools/同步到桌面工具.command` 更新它。
- 每个照片目录下生成的 `_初筛结果/` 是运行数据和页面副本，不是源代码仓库；不要在其中维护功能代码。
- iOS 的 `build/`、`输出/`、Xcode 用户设置以及 Mac 编译缓存均不纳入 Git。它们不会被清理或删除。

## 日常维护

1. 在本仓库修改对应版本的源代码。
2. 执行该版本的构建/检查。
3. Mac 版验证通过后运行 `tools/同步到桌面工具.command`，保持桌面启动包与仓库一致。
4. 查看 `git status`，确认改动后再提交。不要把照片、筛选结果、签名材料或本机 Xcode 用户配置提交进仓库。
