# 拣片 iOS App

原生 SwiftUI iPhone 版本，最低部署版本 iOS 17。照片分析使用 Vision 和设备端图像采样，不上传照片。

## 打开与运行

1. 在安装完整 Xcode 的 Mac 上打开 `拣片.xcodeproj`。
2. 选择 iPhone 模拟器或已连接的 iPhone，设置自己的开发团队后运行。
3. 首次启动时允许照片访问，再选择要整理的相册。

## 当前能力

- 浏览“最近项目”和用户相册并分析相册中的图片。
- 设备端计算清晰度、曝光和视觉特征相似度；相似组按分数排序。
- 手动选择保留、待确认或淘汰；重新打开相同相册时恢复上次决定。
- 文件名与拍摄时间匹配的 RAW/JPEG 项目联动决策。
- 确认后创建或更新“拣片-保留”“拣片-待确认”“拣片-待删除”三个系统相册。

“待删除”只是一张结果相册，不会自动删除原片。分析分数是启发式初筛建议，需人工复核。

## 已知限制

- iCloud 照片可能需要下载预览，网络和相册规模会影响分析时间。
- RAW/JPEG 分开成为两个照片项目时，依赖文件主名和 3 秒内拍摄时间配对。
- 进度目前保存每张照片的决定；重新进入相册时会重新分析预览，再恢复决定。
- 本工作区环境缺少完整 Xcode/iOS SDK，尚不能在此编译、模拟器运行或签名安装。
