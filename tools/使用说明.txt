照片初筛工具

1. 双击桌面上的“拾片.command”；如果没有桌面快捷入口，也可双击“照片初筛工具”文件夹内的“照片初筛工具.command”。
2. 在弹出的窗口中选择包含照片的文件夹。
3. 如果这个目录已筛过，选择“继续上次筛选（直接打开）”；新目录或需要更新分析时，选择“自动识别、人像、风景、夜景、运动”等筛选策略。
4. 浏览器会自动打开初筛页面；使用期间请保持启动的终端窗口打开，关闭它只会停止本地服务，不会删除照片或筛选记录。
5. 手动调整“保留 / 待确认 / 淘汰”；选择会自动保存。
6. 筛选到一半时点击工具栏“暂存进度”；下次打开同一目录，会恢复已选结果、筛选与排序条件，并回到上次浏览位置。
7. 点击工具栏“切换目录”，会先保存当前进度。若所选目录已有“_初筛结果”，会直接恢复暂存或已完成的筛选；否则开始分析新照片，并实时显示阶段、已处理张数和百分比。
8. 连拍或内容相似的照片统一进入“对比组”，点击“打开对比组”并排决定去留。
9. 工作区的“排序”菜单支持推荐顺序、综合分、构图分、拍摄时间、文件名和按对比组排列；排序偏好会保存在本机。
10. 点击“确认筛选并整理文件”，JPG 与对应 RAW 会一起移动到“筛选完成”的三个目录。
11. 如果刚整理完发现有误，可点击“撤销上次整理”恢复原位。
12. 整理后如想沉淀选片习惯，可点击顶部“选片偏好”，再手动点击“总结本次偏好”。工具仅选最多 6 张有辨别力的报告预览图发送给当前 AI 供应商；同一次总结已有草稿时不会重复请求。请勾选、修改或拒绝 AI 的结论，再点“审核后写入”。已确认的偏好可在同一页面修改或删除，后续“AI 帮我看看／AI 帮我选”会参考这些偏好。

说明：
- 基础分析都在本机完成。只有手动点击“AI 帮我看看／AI 帮我选”并点击发送按钮时，所选照片的报告预览图才会发送到选定供应商；原图和 RAW 不会上传。
- AI 可选择 OpenAI API Key、官方 Codex CLI 登录或支持图片输入的兼容 API。Codex CLI 请先在终端运行 codex login；API 模式需要单独的 API Key，可能产生费用。对比组最多发送 6 张照片。
- 页面顶部“配置 AI”是统一入口，可保存、切换多个供应商配置，并使用“测试连接”检查登录或 API。单张照片和对比组共用当前配置。API Key 不写入浏览器长期存储，刷新页面后需重新输入，或在启动前配置 OPENAI_API_KEY。部分兼容供应商不支持 /models，连接测试可能失败，但仍可尝试手动分析一张照片。
- AI 只提供理由和建议，不自动改动“保留 / 待确认 / 淘汰”。
- “确认筛选并整理”本身不调用 AI；若本次没有推翻初筛或对比组的人工取舍，工具不会为了总结空泛偏好而付费请求。Memory 保存在本机的“~/Library/Application Support/拾片/筛选偏好.json”，目前只影响手动 AI 建议，不会自动调整初筛分数或触发淘汰。
- 构图分会参考主体位置、视觉平衡、边缘裁切风险和水平线倾斜；它用于辅助排序，不会单独触发淘汰。
- 选片预览会生成最长边 1600 像素的高清本地缩略图，不修改原图；旧版低清缩略图会在再次分析时自动更新。
- 工具不会直接删除照片。
- 每个照片目录都会生成自己的“_初筛结果”。
- V2 在 macOS 上使用系统自带的 Vision 框架进行离线人脸、主体和可能闭眼分析。
- 页面顶部可展开查看本批筛选策略；每张照片可展开查看清晰度、曝光、对比度、连拍扣分和最终判断依据。
- 工具会用“连续拍摄”和“内容相似”两种方法识别照片，但界面统一显示为“对比组”；卡片仍会标明具体归组依据。
- 点击顶部“对比组”可集中查看全部分组照片，点击卡片的“打开对比组”可并排复核。
- 对比窗口可提交“分组正确 / 这组只留一张 / 拆分此组”。漏识别时，在任意多张照片卡片上点击“加入对比组”，再用页面底部的“创建对比组”一次归组（至少 2 张、最多 30 张）。已有组可点击“追加到此组”，页面会自动选中整组，再选择新照片即可追加；同时选择两个已有组则会合并。
- 创建、追加、移出和拆分会立即更新页面；对比窗口可“添加更多照片”或将单张“从本组移除”。顶部“更多操作”里的“撤销归组”可撤销最近一次相似组操作，最多保留 30 步反馈历史；“撤销整理”和“重置调整”也在此处。
- 分组反馈保存在“_初筛结果/相似分组反馈.json”，下次分析自动应用；累计 20 对后才渐进调整内容识别门槛。
- “初筛清单.csv”包含完整的分项分数与打分说明，便于复核。
- 只有严重失焦、严重曝光错误或连拍中明显较差的照片才会自动进入“淘汰”。
- 工具会参考你以前的手动修改，逐步调整保留阈值和淘汰策略。
- 再次分析同一目录会复用缓存，只重新分析新增或修改过的照片。
- “撤销上次整理”只撤销最近一次整理操作。
- 支持 JPG、JPEG、PNG、WebP、TIFF；可配对 ARW、CR2、CR3、NEF、RAF、DNG 等常见 RAW。
